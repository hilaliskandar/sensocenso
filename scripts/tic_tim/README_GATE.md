# Gate de execução

A branch representa preparação reprodutível, não fechamento estatístico.

O gate do Entorno de Caieiras fecha apenas quando a execução canônica comprovar simultaneamente: 207 setores reconciliados, 7 APONDs, 30 distribuições por território, fechamento dos percentuais bruto e no domínio aplicável e consolidado municipal derivado da soma dos contadores APOND.
